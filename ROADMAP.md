# HHS Mission Control (Unified)

A professional Command Center for business management, task tracking, and knowledge organization. Built for scale and AI-readiness.

## 🚀 Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase (PostgreSQL + pgvector)
- **Validation**: Zod
- **State Management**: Zustand
- **Icons**: Lucide React
